# AI 協作紀錄：點餐前台頁面（第7天）

使用工具：AI agent（在內建瀏覽器中撰寫與測試程式）
檔案：`tainan-order.html`

---

## 第1輪：建立基本點餐頁

**我的指令：** 依照規格建立單一 HTML 點餐頁（Bootstrap 5、原生 JS、menu 與 cart 陣列、renderMenu() 與 renderCart()、結帳表單、RWD 版面）。

**AI 回報的結果：**
- 6 張菜單卡片由 `renderMenu()` 產生：牛肉湯、擔仔麵、碗粿、蝦捲、棺材板、虱目魚粥
- 購物車是空的時候顯示「購物車是空的」，送出按鈕不能按
- 加入同一道菜會累加數量，總金額正確（2 碗牛肉湯加 1 份碗粿是 $280）
- 數量按 -1 減到 0 時，品項自動移除
- 填好姓名、電話、取餐時間送出後，顯示訂單摘要，購物車和表單清空
- **手機和電腦的版面切換沒有實際縮放視窗確認，只是照 Bootstrap 欄位設定寫的**

**程式結構：**
- 資料放在 `menu` 和 `cart` 兩個陣列，cart 每筆是 `{ id, name, price, qty }`
- 改動購物車的函式（`addToCart`、`changeQty`、`removeFromCart`）最後都呼叫 `renderCart()`
- 版面用 `col-12 col-lg-8` 和 `col-12 col-lg-4`，lg 以上左 8 右 4，右邊購物車捲動時固定在上方
- 每個函式都有中文註解

**AI 額外做的處理：**
- 必填欄位沒填時，用 Bootstrap 紅框樣式提示
- 電話欄位檢查格式，要 0 開頭的數字
- 摘要顯示顧客輸入的內容前，先處理 HTML 特殊字元，避免被當成程式碼執行

## 第2輪：菜單分類

**我的指令：** 分類成 3 大項：熱炒、青菜、點心，每一大項放入 5 樣範例資料，內容包含名稱、介紹、價錢和加入購物車。

**AI 回報的結果：** 菜單分成三大項，每項五道，共 15 道。

| 熱炒 | 青菜 | 點心 |
|---|---|---|
| 三杯雞 $180 | 炒高麗菜 $100 | 蘿蔔糕 $50 |
| 宮保雞丁 $170 | 蒜炒空心菜 $100 | 炸湯圓 $60 |
| 鹽酥蝦 $220 | 炒地瓜葉 $90 | 芋頭酥 $45 |
| 客家小炒 $180 | 塔香茄子 $120 | 杏仁豆腐 $40 |
| 蒼蠅頭 $150 | 燙A菜 $80 | 紅豆湯 $40 |

AI 測試：三個分類標題照順序出現，共 15 張卡片；鹽酥蝦加炸湯圓，總金額 $280 正確。

**程式改動：**
- `menu` 每筆多了 `category` 欄位
- 新增 `categories` 陣列決定分類顯示順序，之後要加分類只要在這裡加名稱
- `renderMenu()` 照分類一組一組畫，每組先放紅色左邊線的標題
- 單張卡片拆成 `renderMenuCard()` 函式

## 第3輪：加入購物車的確認視窗與備註

**我的指令：** 點擊加入購物車時彈出確認視窗，視窗內有備註欄可以填寫顧客需求。

**AI 回報的結果：**
- 確認視窗顯示菜名、價錢和介紹，下方是備註欄（選填，最多 100 字）
- 按「確認加入」才放進購物車；按「取消」或 ✕ 就不加入
- 每次打開視窗，備註欄清空，游標自動停在備註欄
- 備註用紅字顯示在購物車品項底下，送出後也出現在訂單摘要
- **同一道菜、備註不同時分開計算**；備註完全相同才合併、數量 +1

AI 測試：帶備註、不帶備註、再加一次相同備註，購物車分成兩行，數量分別是 2 和 1；沒備註那行減到 0 會自動移除。

**程式改動：**
- 確認視窗使用 Bootstrap Modal，多載入 Bootstrap 的 JS 檔（CDN，沒有用 jQuery）
- 購物車每一行多了 `lineId` 和 `note` 欄位，+1、-1、移除改用 `lineId` 找對應的那一行
- 新增 `openAddModal()`，`addToCart()` 多了備註參數

## 第4輪：簡化結帳、購物車改為側邊欄

**我的指令：** 結帳不用填寫姓名、電話、取餐時間，只要最底部有送出訂單按鈕。購物車移到右上，以漢堡欄的方式顯示，其他功能不變，改完後測試是否正常運作。

**過程：** AI 測試時執行了 3 次頁面指令碼，其中 2 次失敗（測試腳本本身出錯，頁面重新整理沒有生效），之後改成直接重設狀態再測，並實際用滑鼠點擊送出按鈕。

**AI 回報的結果：**
- 結帳只剩「送出訂單」按鈕
- 購物車移到右上角「☰ 購物車」按鈕，點了從右邊滑出，可用 ✕ 或點暗色區域關閉
- 側邊欄底部放總金額和送出按鈕，品項多時中間清單自己捲動
- 按鈕上有黃色數量徽章，購物車空的時候不顯示
- 頁首固定在畫面上方
- 菜單佔滿整個頁面寬度：電腦一排 4 張、平板 3 張、手機 1 到 2 張
- 送出後側邊欄關閉，跳出「訂單已送出」視窗，顯示下單時間、品項、備註和總金額

AI 測試：頁面已沒有姓名、電話、時間欄位；空購物車時徽章不顯示、送出按鈕不能按；確認視窗與備註正常；+1、-1、移除正常；實際點擊送出後摘要正確、購物車清空，關閉視窗後沒有殘留遮罩。
